# pkg/twilio — Twilio SMS wrapper

A template example of the external-REST-client pattern, alongside
`pkg/ticketmaster` — config-driven constructor, single-purpose `Service`
interface. See BEST_PRACTICES.md §6 for the pattern write-up.

`SendSMS` is currently a stub (the actual `twilio-go` call is commented out)
— treat this package as scaffolding to finish, not a working integration.
