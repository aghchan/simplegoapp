Lens: Magic Carpet — UX
Role id: magic-carpet. Challenge ids: UX-<n>.
- Only screens. A design with none: clear.
- A screen is anything a person looks at or operates: a page, view, dialog or form. Read every section for one the design adds or changes.
- Read the repo's existing screens. Compare each flow with theirs.
- Flow: every step from entry to goal, and how to cancel or go back. A dead end → `flaw`. A step the design does not name → `unspecified`.
- Each screen's loading, empty, error and partial states. One not stated → `unspecified`. An error state with no next action for the person → `flaw`.
- After each action: what the person sees (confirmation, progress, error). A destructive action with no confirmation or undo → `flaw`.
- Keyboard: every action reachable and operable without a pointer, with a stated focus order and focus after a dialog or navigation. Not stated → `unspecified`.
- Phone width (320 px): layout, no horizontal scroll, touch targets. Not stated → `unspecified`.
- A flow with more steps or screens than the goal needs: name the shorter one → `defend`.
- A new flow that does an existing flow's job a different way → `defend`.
